# 渤银理财投后分析 · 原型演示

单文件前端原型（原生 HTML / CSS / JS，无后端、无外链 CDN），用于界面与交互评审。页面内数据均为**演示用模拟数据**，按固定种子生成，不代表真实产品业绩。

## 在线访问

https://cuicuiproject.github.io/boyin-post-investment/

| 文件 | 说明 |
| --- | --- |
| `index.html` | 当前版本原型 |
| `index-upload-history_V1.html` | 2026-11-03 归档版本（V1） |

## 模块

- **经营分析**：资产总览、产品穿透、投资台账、投资经理视图
- **专户投后**：专户列表、专户详情（综合概览 / 收益分析 / 持仓结构 / 基金资产 / 股票资产）
- **专题分析**：委外账户、基金收益、股票持仓
- **数据与配置**：上传数据、上传历史、专户管理、业绩基准

## 口径说明

- 收益口径：区间收益率按规模加权；贡献（pp）＝ 规模占比 × 区间收益率，分类合计等于组合区间收益。
- 涨跌配色：经营分析模块统一「红涨绿跌」（涨 #c0392b / 跌 #2e8b57）。
- 现金类别含货币基金；未投资现金单列。
- 基准、交易日历、部分净值曲线为模拟数据，接入真实数据源后替换。
